## What's needed (House delta, in dependency order)

1. **Proxy route** — one same-origin Pages Function (`/api/muse/intent` first) with shape validation, model allowlist, per-request ceilings, Q1 aggregate meter, breaker, closed error taxonomy. No storage of content; counts only.
2. **Provider interface** — narrow shapes (`intent` now; `explain`/`briefing`/`transcribe` specified, not built) so the post-contest model swap is a provider swap.
3. **Validator interface** — 6-step fail-closed contract imported from the pad path; hermetic stub here until the pad lands. Single source stays in the pad; Entire never duplicates the implementation.
4. **Ask UI** — text input + editable intent chips + clarification state + figure rendering through existing cards + disclosure on the surface.
5. **Meter** — Durable Object aggregate counter (counts only), reservation/settlement, per-client cap support (value set at S10, not invented here), hard shutoff at the §6.4 judging cap.
6. **Disclosure** — every AI surface: figures are CivicScope's (source + vintage), wording is Muse Spark's; D5 structured slots over raw text wherever the feature allows; audio transit disclosed for mic.
7. **Mic (LAST)** — first-class + accessible: equal main input, keyboard path intact, transcript → editable chips, low-confidence → clarification, spoken numbers through the same validator, first-use consent before any mic use. Not built in this session (see plan).
8. **Fallback parity** — AI off / keyless / model down ⇒ full pre-hackathon CivicScope; drilldown intact without any key.
